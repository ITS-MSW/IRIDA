# Third-party notices

## React Grab integration

IRIDA imports `getElementAtPoint`, `getElementBounds`, and `isElementGrabbable` from the published `react-grab/primitives` entry point in **react-grab 0.2.0**, pinned in `package.json` and `bun.lock`. No upstream source files were vendored or modified.

Selection implementation, README, license, exports, overlay filtering, ignored subtrees, bounds caching, and interaction code were inspected at upstream commit [`ea4bbec9e80f4802e8ae19ad18431edb9ddbb670`](https://github.com/aidenybai/react-grab/tree/ea4bbec9e80f4802e8ae19ad18431edb9ddbb670). Installed package exports and TypeScript declarations were checked separately; this repository commit is the study reference, not a claim that the published archive is identical to main.

The local adapter normalizes the actual `{ x, y, width, height, borderRadius }` return type, restricts selection to the top-level document, and adds explicit composed-tree exclusion for IRIDA's host. IRIDA's controller supplies activation, parent/child history, confirmation, cancellation, and capture. Fresh native bounds supplement upstream's cached highlight bounds at capture checkpoints. React Grab's auto-start entry point, context copying, editor and agent workflows, and `freeze()` are not used.

The following notices cover the directly reused library and bundled runtime dependencies. Build-only dependency licenses remain in their respective installed packages. Original license banners are retained in the production bundle.
